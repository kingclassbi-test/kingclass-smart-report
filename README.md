# 📊 KingClass Smart Report (AI Dashboard)

ระบบสรุปยอดขายและข้อมูลนักเรียนของ KingClass Academy แบบอัตโนมัติ  
พร้อมวิเคราะห์ข้อมูลด้วย AI ในรูปแบบ Dashboard ที่ดูเป็นมืออาชีพ ใช้งานง่าย  
รองรับการอัปโหลดไฟล์ Excel รายได้ของสาขาทั้งหมด

---

## 🚀 ฟีเจอร์ของระบบ

### ✔ Dashboard อัตโนมัติ
- ยอดขายรวม / จำนวนนักเรียนรวม
- ตัวชี้วัดรายภาค (Regional Performance)
- Top 10 สาขายอดขายสูงที่สุด
- กราฟสรุปด้วย Plotly แบบสวยทันสมัย

### ✔ AI วิเคราะห์ผล
ระบบจะสรุปข้อมูลให้แบบผู้บริหารอ่านง่าย เช่น
- ภาพรวมยอดขาย
- สาขาที่เด่นที่สุด
- ภาคที่เติบโตเร็ว
- สาขาที่ควรจับตา
- คำแนะนำเชิงกลยุทธ์ของ HQ

### ✔ AI Q&A Chatbot
สามารถถามคำถามเกี่ยวกับข้อมูลได้ เช่น:
- “สาขาไหนรายได้สูงสุด?”
- “ภาคไหนเติบโตเร็วสุด?”

และ AI จะตอบโดยใช้ข้อมูลใน Excel ที่อัปโหลด

---
